Quality settings · next slice only

Default 0 disables hole compensation. Positive values enlarge internal XY openings: +0.2 mm per edge increases a circular hole's diameter by about 0.4 mm. Negative values shrink openings. Clear the field to use the server profile.

Default 0 disables outer-contour compensation. Negative values shrink outer dimensions: −0.2 mm per edge reduces width/diameter by about 0.4 mm. Positive values enlarge them. Clear for server profile. Hole compensation is separate.

These are fixed XY edge offsets, not whole-model scaling or Z correction. Larger holes or smaller outer contours can thin or remove narrow walls; inspect the output and try a small calibration part. First-layer height and retraction are not changed.

Try a 5 mm outer brim for lifting corners. Extra material must be removed and can mark the bottom edge. Keep the bed clean/level and avoid drafts. Brim needs additional space around the model; Orca may reject a plate that no longer fits.

First-layer height and brim separation use the server profile; temperature, start/end code and retraction are unchanged. These controls do not change an already sliced file or running print. To change a completed slice, discard/reselect and slice again.
